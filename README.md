# MSP430_FR6989 Project 

Developed a firmware in C for the MSP430FR6989, using Code Composer for the
Embedded Software application, implementing a scheduler to manage five concurrent
system tasks and peripheral integration.

-Programmed the MSP430 microcontroller in C to execute a cyclic routine of five distinct
operational tasks.

-Configured on-board peripherals (GPIO, Timers, ADC) for efficient task scheduling.

-Implemented a simple LED alert controlled with a button.
